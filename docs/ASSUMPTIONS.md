# Autonomous Assumptions

- This is a new project; no existing repository matching the one-prompt game project was found, so unrelated existing repositories must remain untouched.
- The quality benchmark refers to production discipline and finish, not content volume or genre imitation.
- A compact finite single-player action game gives the best quality-to-scope ratio for one autonomous build.
- User accounts, cloud saves, multiplayer, monetization, and a database are not required unless the selected design derives direct value from them; this design does not.
- Modern evergreen desktop/mobile browsers with Canvas2D, ES modules, Web Audio, Pointer Events, and localStorage are the supported platform baseline.
- Mobile play is landscape-first; desktop is the primary high-quality presentation target.
- System typography is preferable to a remote font dependency for this release because the UI language is technical and can remain intentional without a download.
- LocalStorage best score/settings are convenience state, not trusted competitive progression.
